# 小智安卓手机安装指南 📱

## 一、安装小智到桌面（PWA方式）

### Chrome浏览器
1. 打开小智网址
2. 点击右上角菜单 (⋮)
3. 选择「添加到主屏幕」或「安装应用」
4. 点击「安装」
5. 桌面会出现小智图标！

### 其他浏览器
- **Edge**: 菜单 → 添加到手机
- **Firefox**: 菜单 → 安装
- **三星浏览器**: 菜单 → 添加到主屏幕

---

## 二、权限配置

安装后请授予以下权限：

### 必需权限
| 权限 | 用途 | 如何开启 |
|-----|-----|---------|
| 🎤 麦克风 | 语音对话 | 设置 → 应用 → 小智 → 权限 → 麦克风 |
| 🔔 通知 | 接收提醒 | 设置 → 应用 → 小智 → 通知 |
| 📱 后台运行 | 保持连接 | 设置 → 电池 → 小智 → 不限制 |

### 可选权限
| 权限 | 用途 |
|-----|-----|
| 📍 位置 | 本地天气、附近服务 |
| 📷 相机 | 拍照识别、AR功能 |
| 📁 存储 | 保存文件、离线模型 |

## 三、语音唤醒配置

### 方法1：使用小智内置唤醒
1. 打开小智应用
2. 进入设置 → 语音设置
3. 开启「语音唤醒」
4. 设置唤醒词（默认「小智」「小智小智」）
5. 保持应用在前台或后台运行

### 方法2：配合系统语音助手
**三星 Bixby**:
1. 设置 → Bixby → 语音唤醒
2. 创建Bixby指令：说「小智」时打开小智应用

**华为 小艺**:
1. 设置 → 智慧助手 → 语音控制
2. 创建快捷指令打开小智

**小米 小爱**:
1. 小爱设置 → 快捷指令
2. 添加「打开小智」指令

## 四、本地AI模型安装

### 步骤1：安装MLC LLM
1. 访问 https://llm.mlc.ai/
2. 下载Android APK
3. 安装（允许未知来源）

### 步骤2：下载模型
推荐16GB手机使用：
```
Qwen2-7B-Instruct-Q8_0.gguf (7.7GB)
https://huggingface.co/Qwen/Qwen2-7B-Instruct-GGUF
```

### 步骤3：配置模型
1. 打开MLC LLM
2. 点击「Load Model」
3. 选择下载的.gguf文件
4. 等待加载完成

### 步骤4：启动服务器
1. MLC LLM设置 → 开启Server Mode
2. 记录显示的IP地址（如192.168.1.100:8080）

### 步骤5：连接小智
1. 打开小智 → 精灵控制
2. 注册新设备 → 填入IP地址
3. 完成！

## 五、省电优化

### 推荐设置
1. **关闭「自动同步」** - 使用时才同步
2. **开启「深色模式」** - 在设置中开启
3. **调低「屏幕亮度」** - 使用自动亮度
4. **本地模型按需启动** - 不用时关闭MLC LLM

### 电池用量估算
| 场景 | 预计耗电 |
|-----|---------|
| 纯文字对话（云端） | ~3%/小时 |
| 语音对话 | ~5%/小时 |
| 本地AI推理 | ~8%/小时 |
| 后台待命 | ~1%/小时 |

## 六、常见问题

### Q: 语音唤醒不灵敏？
A: 进入设置 → 语音设置 → 提高唤醒灵敏度

### Q: 后台被系统杀死？
A: 设置 → 电池 → 小智 → 允许后台活动

### Q: 本地模型加载慢？
A: 第一次加载需要2-3分钟，之后会快很多

### Q: 手机发热？
A: 本地AI推理会发热，建议：
- 降低推理温度(temperature)
- 使用Q4量化模型代替Q8
- 不要边充电边使用
