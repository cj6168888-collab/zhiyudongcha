🎨 UI 视觉层详细策划（AI 程序员必读）
【启动界面：上帝协议入口】
• 视觉描述：屏幕中心是一个微小的发光点。当用户手指触碰时，屏幕背景浮现密集的代码流，粒子迅速向指尖汇聚成一个分形球体。
• 操作秘密：左上角连续点击 5 次触发 isMaster 验证弹窗（输入 API Key 和 IP）。
【主人端：移动指挥部】
• 功能布局：
• 顶部：HP 算力环（根据 Z1 实时同步），学术等级勋章（本科→专家）。
• 中部：服务器任务列表（显示服务器 Z6 正在代下的软件、影视、图书进度）。
• 底部：分身节点管理（查看发送给团队、股东的分身活跃状态）。
【访客端：形象打造舱】
• 人物定制：提供 3D 渲染的二次元模型。用户可调整发色（RGB 滑块）、体型、性格标签。
• 商务泡泡：若用户选择商务模式，二次元形象会“化为一道光”缩回屏幕右侧，变成一个带呼吸灯效果的半透明圆球（Bubble）。
