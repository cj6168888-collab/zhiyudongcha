# MVP 范围

## MVP 目标

跑通第一条主闭环：

```text
觉醒
  -> 对话输入
  -> 理解结构化
  -> 候选记忆
  -> 创建项目/任务
  -> 高风险确认
  -> 执行或计划
  -> 回流结果
```

## 必须包含

### 1. 身份觉醒

- 名字。
- 主人称呼。
- 关系。
- 人格。
- 声音预设。
- 基础记忆授权。
- 基础执行边界。

### 2. 对话主入口

- 文本输入。
- 语音输入或录音导入。
- 模式识别。
- 结构化理解卡。
- 闲聊不强行结构化。

### 3. 记忆

- 候选记忆。
- 确认保存。
- 查看来源。
- 修改/删除。

### 4. 项目

- 从对话创建项目。
- 项目摘要。
- 任务列表。
- 风险点。

### 5. 任务

- 即时任务。
- 定时任务。
- 状态展示。
- 完成回流。

### 6. 守护

- 风险等级。
- 高风险确认。
- 审计记录。
- 敏感外传拦截。

### 7. 模型/工具

- 基础 ModelRouter。
- 基础 ToolRegistry。
- Provider 可替换。
- 预算字段预留。

## 暂不包含

MVP 暂不强求：

- 完整蜂群治理。
- 完整 App 自动操作。
- 完整邮件/照片/文件全量索引。
- 声音克隆。
- 完整梦境自优化。
- 多组织复杂权限。

这些进入 P1/P2。

## MVP 验收语句

主人第一次打开系统，可以完成觉醒；随后自然说一件复杂的事，系统能理解、生成候选记忆、创建项目和任务、需要确认时请求确认，并在完成后回流结果。
