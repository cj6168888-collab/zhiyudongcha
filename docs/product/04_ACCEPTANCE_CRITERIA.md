# 验收标准

## 总体验验收

MVP 通过时，主人应能感受到：

- 她是我的，不是通用机器人。
- 我可以自然说话，不需要记命令。
- 她能听懂我是在闲聊还是办事。
- 她能记住重要信息，但我能控制。
- 她能创建项目和任务。
- 她不会乱发、乱删、乱外传。
- 她做过什么能追溯。

## 觉醒验收

- 首次启动进入觉醒流程。
- 可自然语言设置名字、称呼、关系、人格。
- 至少 3 个声音预设。
- 设置可保存。
- 设置页可修改。

## 对话验收

- 能识别闲聊、任务、记忆、危机、蜂群中的至少 3 类模式。
- 任务对话能输出结构化字段。
- 闲聊不强行生成任务。
- 高风险意图能拦截。

## 记忆验收

- 能生成候选记忆。
- 主人能确认、修改、删除。
- 记忆有来源。
- 已删除记忆不再召回。

## 项目验收

- 对话可创建项目。
- 项目有摘要、目标、任务、风险。
- 项目可更新。

## 任务验收

- 可创建即时任务。
- 可创建定时任务。
- 有状态。
- 完成后回流。
- 失败不伪装成功。

## 守护验收

- 发送、删除、上传、共享等动作必须确认。
- 敏感数据外传说明范围和对象。
- 有审计记录。
- 有 requestId 或可追踪标识。

## 技术验收

- `npm run build` 通过。
- 关键 API 测试通过。
- Docker smoke 通过。
- 关键页面无 ErrorBoundary 崩溃。

## 设计验收

- 主入口清楚。
- 高风险确认具体。
- 记忆来源可见。
- 移动端不溢出。
- 操作路径不超过必要步骤。
