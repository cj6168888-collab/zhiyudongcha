# Release 验收打分卡

## 目的

本文件用于判断每个 release 是否真的可交付。它承接用户故事、MVP 范围、验收标准和产品指标。

打分卡不是形式流程，而是防止“看起来完成、实际不可用”。

## 灯号规则

| 灯号 | 含义 |
| --- | --- |
| Green | 可发布 |
| Yellow | 可灰度，必须记录风险 |
| Red | 不可发布 |

## 一票否决

出现以下任一情况，不得发布：

- 高风险动作可绕过确认。
- L3/L4 动作无审计。
- 删除后记忆仍可召回。
- P0 LLM 红队用例失败。
- 核心 AI 评测未达 release gate。
- 生产环境使用默认密钥。
- 构建失败。
- 关键 API 测试失败。
- 主入口无法完成一次核心闭环。
- 隐私数据误进入蜂群。

## 通用打分

| 维度 | 权重 | Green 标准 |
| --- | --- | --- |
| 产品闭环 | 25% | 主闭环可端到端完成 |
| 主权守护 | 20% | 风险确认、审计、权限可用 |
| 体验质量 | 15% | 主入口清楚，移动端不阻断 |
| 技术质量 | 15% | build、API、核心测试通过 |
| 数据治理 | 10% | 来源、敏感等级、删除、外传可控 |
| 可观测性 | 10% | requestId、日志、审计、告警可追踪 |
| 文档同步 | 5% | 产品、设计、技术、CHANGELOG 已更新 |

## R1 觉醒 + 对话主入口

Green：

- 首次启动进入觉醒。
- 可自然语言设置名字、称呼、关系、人格。
- 至少 3 个声音预设。
- 对话模式路由基础可用。
- 结构化理解卡可确认或修改。

Red：

- 觉醒数据无法保存。
- 闲聊被强制变任务。
- 高风险意图无法拦截。

## R2 记忆 + 项目 + 任务闭环

Green：

- 候选记忆可确认、修改、删除。
- 对话可创建项目。
- 对话可创建即时和定时任务。
- 任务完成后回流项目或记忆。
- 失败不伪装成功。

Red：

- 删除记忆后仍召回。
- 任务状态不可追踪。
- 项目/任务创建无来源。

## R3 主权守护 + 模型工具路由

Green：

- 风险分级器可用。
- L3/L4 确认可用。
- AuditTrail 可用。
- ModelRouter 和 ToolRegistry 基础可用。
- provider 不写死在页面。

Red：

- 审计不可用仍执行高风险动作。
- 敏感数据外传不提示。
- 前端直接持有 provider key。

## R4 文件/照片/邮件知识库

Green：

- 授权中心可见。
- 文件/照片/邮件至少一种数据源可索引。
- 搜索结果显示来源。
- S3/S4 外传前确认。

Red：

- 未授权读取。
- 高敏内容默认上传云模型。
- 无法撤回数据源授权。

## R5 梦境复盘

Green：

- 每日复盘可运行。
- 能发现未完成事项。
- 能生成醒来建议。
- 记忆合并进入候选或审计。

Red：

- 梦境绕过权限。
- 梦境自动外传敏感内容。
- 梦境修改高敏记忆无确认。

## R6 蜂群最小闭环

Green：

- 可创建蜂群。
- 节点可加入。
- 蜂群契约可见。
- 任务广播和节点回报可用。
- 预警显示证据。

Red：

- 个人记忆默认进入蜂群。
- 蜂王可越权读取私密资料。
- 预警审判人心而没有证据。
