# 发布计划

## R0 文档基线

目标：完成产品、技术、设计、产品交付文档基线。

状态：进行中。

交付：

- 产品 canonical 文档。
- 技术基线。
- 设计基线。
- 用户故事和功能清单。

## R1 个体觉醒 + 对话主入口

目标：让她成为“你的她”，并能从自然语言开始工作。

范围：

- 觉醒问询。
- 身份和人格保存。
- 声音预设。
- 对话模式路由基础版。
- 结构化理解输出。

## R2 记忆 + 项目 + 任务闭环

目标：自然对话能沉淀为记忆、项目和任务。

范围：

- 候选记忆。
- 记忆管理。
- 从对话创建项目。
- 即时任务。
- 定时任务。
- 回流结果。

## R3 主权守护 + 模型工具路由

目标：让强能力可控、可审计、可替换。

范围：

- 风险分级。
- 高风险确认。
- 审计。
- ModelRouter。
- ToolRegistry。
- Provider adapter。

## R4 文件/照片/邮件知识库

目标：开始建立主人资料世界模型。

范围：

- 文件索引。
- 图片 OCR。
- 邮件接入。
- 搜索和来源显示。
- 敏感外传确认。

## R5 梦境复盘

目标：让她每天整理、复盘和提醒。

范围：

- 每日复盘。
- 未完成事项。
- 项目风险。
- 记忆合并。
- 醒来建议。

## R6 蜂群最小闭环

目标：创建蜂群、节点加入、广播任务、回传战报。

范围：

- 蜂群创建。
- 节点加入。
- 蜂群契约。
- 任务广播。
- 节点回报。
- 风险预警。

## 发布纪律

每个 release 必须：

- 更新对应产品文档。
- 更新技术/设计文档。
- 有验收清单。
- 通过必要测试。
- 不引入未审计的高风险动作。
