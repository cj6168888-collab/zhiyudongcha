# 自然语言任务执行系统

## 核心能力

**不需要任何预设配置**。用户用自然语言下达指令，AI 自动：

1. **理解意图** - 分析用户想做什么
2. **自主调研** - 自己上网搜索、访问网站
3. **分析页面** - 理解网站结构和表单
4. **制定计划** - 规划执行步骤
5. **自动执行** - 一步步完成任务
6. **自我反思** - 失败时自己想办法修正

## API 接口

### POST /api/agent/nl

处理自然语言指令。

**请求：**
```json
{
  "command": "帮我查一下科技局的最新政策",
  "context": {
    "companyInfo": {
      "name": "公司名称",
      "creditCode": "统一社会信用代码"
    }
  }
}
```

**响应：**
```json
{
  "success": true,
  "taskId": "task_abc123",
  "requiresInput": false,
  "steps": [
    {
      "id": "understand-intent",
      "description": "理解用户意图",
      "success": true,
      "output": {
        "type": "inquiry",
        "entities": {
          "governmentDept": "科技局"
        }
      }
    },
    {
      "id": "navigate-1",
      "description": "搜索科技局",
      "success": true,
      "output": {
        "url": "https://www.google.com/search?q=..."
      }
    },
    {
      "id": "analyze-1",
      "description": "分析搜索结果",
      "success": true,
      "output": {
        "analysis": "找到以下政策..."
      }
    }
  ],
  "reflections": [],
  "finalResult": {
    "totalSteps": 3,
    "successfulSteps": 3
  }
}
```

### GET /api/agent/nl/capabilities

获取支持的能力列表和示例。

```bash
curl http://localhost:3001/api/agent/nl/capabilities
```

## 支持的指令类型

| 类型 | 示例 | 说明 |
|------|------|------|
| **inquiry** | "查一下科技局政策" | 查询信息 |
| **application** | "帮我申报高企认定" | 申报申请 |
| **monitor** | "监控税务回复" | 定期监控 |
| **report** | "生成本周工作摘要" | 生成报告 |
| **search** | "搜索最新法规" | 搜索内容 |
| **automation** | "每天提醒我日报" | 自动化任务 |

## 执行流程

```
用户: "帮我查一下高新技术企业认定的申报条件"

     │
     ▼
┌─────────────────────────┐
│   意图理解 (Intent)     │
│  type: "inquiry"        │
│  entities: ["高企认定"]  │
└─────────────────────────┘
     │
     ▼
┌─────────────────────────┐
│   任务规划 (Planning)   │
│  1. 搜索高企认定        │
│  2. 分析科技局网站      │
│  3. 提取申报条件        │
│  4. 汇报结果            │
└─────────────────────────┘
     │
     ▼
┌─────────────────────────┐
│   自主执行 (Execution)   │
│                         │
│  navigate → analyze →   │
│  extract → report       │
│                         │
│  每步失败时自我反思      │
└─────────────────────────┘
     │
     ▼
用户: 收到汇报结果
```

## 自我反思机制

当执行失败时，AI 会：

1. **分析原因** - 为什么这一步失败了
2. **制定策略** - 怎么解决这个问题
3. **重新尝试** - 用新方法再试一次
4. **汇报困难** - 如果实在解决不了，告诉用户需要什么帮助

**示例反思：**

```
反思：登录失败，可能是因为页面结构变了。
解决方案：
1. 先分析登录页面的实际结构
2. 重新定位用户名密码输入框
3. 尝试不同的选择器

重新尝试...
```

## 使用示例

### 示例1: 查询政策

```bash
curl -X POST http://localhost:3001/api/agent/nl \
  -H "Content-Type: application/json" \
  -d '{
    "command": "查一下2024年科技型中小企业扶持政策"
  }'
```

### 示例2: 协助申报

```bash
curl -X POST http://localhost:3001/api/agent/nl \
  -H "Content-Type: application/json" \
  -d '{
    "command": "帮我申报科技型中小企业认定",
    "context": {
      "companyInfo": {
        "name": "某某科技有限公司",
        "creditCode": "91110000XXXXXXXX",
        "employeeCount": "50",
        "rdExpense": "200万"
      }
    }
  }'
```

### 示例3: 创建监控任务

```bash
curl -X POST http://localhost:3001/api/agent/nl \
  -H "Content-Type: application/json" \
  -d '{
    "command": "每天早上9点检查税务局网站，有新通知就告诉我"
  }'
```

## 技术架构

```
┌─────────────────────────────────────────────────────────────┐
│                    自然语言指令                               │
│              "帮我查科技局最新政策"                           │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│              Intent Understanding (意图理解)                  │
│         使用 AI 分析用户想做什么                              │
│                      ↓                                      │
│              UserIntent: {                                   │
│                type: "inquiry",                              │
│                entities: ["科技局", "政策"]                   │
│              }                                               │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                Task Planning (任务规划)                       │
│         使用 AI 制定执行计划                                 │
│                      ↓                                      │
│              TaskPlan: [                                    │
│                { type: "navigate", url: "google.com" },       │
│                { type: "analyze", analysis: "..." },         │
│                { type: "extract", fields: [...] },           │
│                { type: "report" }                            │
│              ]                                               │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                   ReAct Loop (执行循环)                      │
│                                                              │
│   ┌─────────┐    ┌─────────┐    ┌─────────┐                │
│   │ Reason  │ →  │  Act    │ →  │ Observe │                │
│   │ (推理)  │    │ (行动)  │    │ (观察)  │                │
│   └─────────┘    └─────────┘    └─────────┘                │
│        ↑                                           │        │
│        └───────────────────────────────────────────┘        │
│                                                              │
│   每个步骤后：                                               │
│   - 成功？继续下一步                                        │
│   - 失败？自我反思 → 调整策略 → 重试                         │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                  Browser Automation                          │
│              (Playwright 浏览器控制)                         │
│                                                              │
│   - 自主导航到目标网站                                       │
│   - 分析页面结构                                             │
│   - 识别表单字段                                             │
│   - 填写并提交                                               │
│   - 提取结果                                                 │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                     汇报给用户                               │
│         App推送 / 邮件 / 短信 / 语音                         │
└─────────────────────────────────────────────────────────────┘
```

## 与预设配置模式的对比

| 能力 | 预设配置模式 | 自然语言模式 |
|------|-------------|-------------|
| 网站配置 | 需要人工配置 | AI 自动分析 |
| 表单结构 | 需要预设字段 | AI 自动识别 |
| 登录凭证 | 需要配置 | 需要提供 |
| 执行流程 | 预设步骤 | AI 规划 |
| 错误处理 | 固定逻辑 | 自我反思 |
| 适应新网站 | 需要新配置 | 自动适应 |
