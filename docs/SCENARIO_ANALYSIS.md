## 二、高频场景详解（路由直达）

### 特征
- 日常频繁使用
- 意图明确，不易混淆
- 操作简单，风险低
- 用户期望即时响应

### 2.1 日程管理 ⭐⭐⭐⭐⭐

```
场景描述：
用户会频繁查看/创建/修改日程

示例对话：
"明天上午10点开会"
"明天有什么安排"
"帮我取消明天的会议"
"把这个会议改到下午3点"

处理方式：路由直达日历服务
响应时间：< 100ms

权限设计：
• 查看日程：自动（无隐私风险）
• 创建日程：自动（自己的日程）
• 修改日程：确认（涉及他人时间）
• 删除日程：确认（避免误删）
```

### 2.2 闹钟提醒 ⭐⭐⭐⭐⭐

```
场景描述：

• 删除提醒：自动

注意：用户开车时，主动建议使用语音提醒

## 三、中频场景详解（混合处理）

### 特征
- 使用频率中等
- 意图可能不完全明确
- 操作有一定复杂性
- 可能涉及多个步骤

### 3.1 会议安排 ⭐⭐⭐

```
场景描述：
安排团队会议

示例对话：
"明天上午要开周会"
"安排一个和小明的1v1"
"创建下周的评审会议"
"帮我发个会议邀请"

处理方式：AI 理解 + 路由执行
响应时间：< 500ms

AI 负责：
• 解析会议主题
• 确定参与人员
• 生成会议议程
• 提取相关资料

路由负责：
• 创建日历事件
• 发送会议邀请
• 收集参会确认

权限设计：
• 创建会议：确认（占用他人时间）
• 修改会议：确认
• 取消会议：确认
• 发送邀请：自动

特殊处理：
• 涉及多人 → 需要确认
• 涉及领导 → 需要确认
• 重复会议 → 自动设置循环
```

### 3.2 预订服务 ⭐⭐⭐

```
场景描述：
酒店、餐厅、票务预订

示例对话：
"帮我订个酒店"
"预订餐厅，要包间"
"买张去北京的火车票"
"帮我订周一早上的机票"

处理方式：AI 理解 + 推荐 + 路由执行
响应时间：< 1s

AI 负责：
• 理解预订需求
• 推荐合适选项
• 提取偏好信息

路由负责：
• 查询可用资源
• 执行预订
• 发送确认

权限设计：
• 查看推荐：自动
• 提交预订：授权（涉及支付）
• 取消预订：授权

安全措施：
• 小额（<100元）：确认即可
• 中额（100-1000元）：输入密码
• 大额（>1000元）：双重确认
• 首次预订：需要授权
```

### 3.3 出行安排 ⭐⭐⭐

```
场景描述：
出差、旅游等行程规划

示例对话：
"帮我安排下周的出差"
"规划一条自驾游路线"
"我周末想去周边玩"

处理方式：AI 规划 + 路由执行
响应时间：< 2s

AI 负责：
• 理解出行目的
• 规划行程
• 协调多个服务

路由负责：
• 预订交通
• 预订住宿
• 景点信息

权限设计：
• 生成方案：自动
• 执行预订：授权
• 修改行程：确认

注意：
• 涉及多天多地，需要 AI 综合规划
• 预算限制需要明确询问
```

### 3.4 智能推荐 ⭐⭐⭐

```
场景描述：
个性化推荐

示例对话：
"附近有什么好吃的"
"推荐个周末去的地方"
"送人送什么礼物好"
"有什么好电影"

处理方式：AI 推荐
响应时间：< 500ms

AI 负责：
• 分析用户偏好
• 匹配推荐
• 生成推荐理由

权限设计：
• 获取位置：确认（首次）
• 使用历史偏好：自动
• 推送优惠：询问

注意：
• 基于位置推荐需要位置权限
• 考虑用户历史行为
• 隐私保护
```

## 四、低频场景详解（AI处理）

### 特征
- 使用频率低
- 意图不明确
- 操作复杂或个性化强
- 需要深度理解

### 4.1 情感陪伴 ⭐⭐

```
场景描述：
情感交流、倾听

示例对话：
"最近好累"
"心情不好"
"陪我聊聊天"
"我有点焦虑"

处理方式：AI 情感处理
响应时间：< 1s

AI 负责：
• 识别情感状态
• 表达共情
• 提供建议
• 适当关心

权限设计：
• 主动关心：自动（但要有分寸）
• 建议休息：自动
• 推荐咨询师：询问

注意事项：
• 不要过度追问
• 不要给医疗建议
• 严重情况建议寻求专业帮助
• 记录情绪变化趋势
```

### 4.2 工作总结 ⭐⭐

```
场景描述：
工作总结、汇报

示例对话：
"帮我总结下这周的工作"
"写个工作汇报"
"分析下这个项目的进展"

处理方式：AI 生成
响应时间：< 2s

AI 负责：
• 收集工作数据
• 整理工作内容
• 生成总结报告

数据来源：
• 日历事件
• 项目管理系统
• 文档协作记录

权限设计：
• 访问工作数据：授权
• 生成报告：自动
• 分享报告：确认
```

### 4.3 复杂规划 ⭐⭐

```
场景描述：
复杂任务规划

示例对话：
"帮我规划下这个项目"
"分析下市场情况"
"给我一些建议"

处理方式：AI 深度分析
响应时间：< 3s

AI 负责：
• 理解复杂需求
• 分析现状
• 生成方案
• 评估风险

权限设计：
• 访问相关数据：授权
• 生成方案：自动
• 执行方案：分步授权
```

### 4.4 创意写作 ⭐⭐

```
场景描述：
文案、邮件等创意内容

示例对话：
"帮我写一封邮件"
"润色下这段话"
"想个广告语"

处理方式：AI 生成
响应时间：< 1s

AI 负责：
• 理解写作目的
• 生成内容
• 根据反馈修改

权限设计：
• 生成内容：自动
• 保存草稿：自动
• 发送/发布：确认
```

### 4.5 闲聊 ⭐⭐

```
场景描述：
日常闲聊

示例对话：
"今天有什么新闻"
"讲个笑话"
"你觉得AI会取代人类吗"

处理方式：AI 对话
响应时间：< 1s

AI 负责：
• 自然对话
• 保持友好
• 适度有趣

注意事项：
• 不要谈论政治敏感话题
• 不要传播谣言
• 涉及争议话题保持中立
```

授权后：
• 记住用户偏好
• 后续同类型操作自动执行
• 可随时在设置中修改
```

### 6.2 额度提升

```
用户行为 → 额度提升：

累计成功操作 10 次 → 额度 +100
累计成功操作 50 次 → 额度 +500
累计成功操作 100 次 → 额度 +1000

降级机制：
• 操作失败 3 次 → 降低一个额度档
• 异常操作 → 直接要求授权
```

### 6.3 动态授权

```
根据上下文动态调整权限：

场景1：用户说"待会帮我提醒xxx"
    → 自动推断为"30分钟后提醒"
    → 🟢 自动执行

场景2：用户说"帮我转1000给李四"
    → 检测到金额较大
    → 🟠 需要授权
    → "请确认转账1000元给李四"

场景3：用户连续操作多个
    → 前一个成功 → 后一个简化确认
    → 前一个失败 → 后一个严格确认
```

## 七、异常处理

### 7.1 权限异常

```
情况1：权限被拒绝
    → "我没有权限访问[功能]，需要在设置中授权"
    → 提供跳转链接

情况2：权限过期
    → "您的[权限]已过期，需要重新授权"
    → 引导重新授权

情况3：部分权限
    → "我可以部分帮你，但有些功能需要额外权限"
    → 尽量在有限权限内完成任务
```

### 7.2 操作异常

```
情况1：操作失败
    → 分析原因
    → 提供替代方案
    → "餐厅预订失败了，要试试另一家吗？"

情况2：执行超时
    → "正在处理中，请稍候..."
    → 超过10秒未响应 → 提示用户
    → 提供取消选项

情况3：结果不确定
    → "操作似乎成功了，但我不确定，要我帮你确认下吗？"
    → 提供验证选项
```
