# 前端深度交互体验测试计划

## 测试范围概述

基于对应用核心功能的分析，制定以下深度交互测试计划：

### 核心功能模块

| 模块 | 功能 | 测试重点 |
|------|------|----------|
| 实时语音对话 | WebSocket连接、ASR识别、TTS播放 | 连接稳定性、延迟、打断功能 |
| 语音活动检测 | VAD检测、能量计算 | 检测准确性、误检率 |
| 声纹识别 | 声纹录入、授权管理 | 识别精度、用户体验 |
| 语音唤醒 | 唤醒词检测、命令执行 | 响应速度、误唤醒率 |
| 设置管理 | 语音配置、权限管理 | 配置保存、状态同步 |

## 测试场景分类

### 1. 语音对话场景测试

#### 场景1.1: 基础语音对话流程
- 步骤1: 用户进入对话页面
- 步骤2: 点击"连接语音服务"
- 步骤3: 等待WebSocket连接建立
- 步骤4: 点击"开始对话"按钮
- 步骤5: 模拟语音输入
- 步骤6: 验证ASR识别结果显示
- 步骤7: 验证TTS音频播放
- 验证点: 状态流转、延迟、错误处理

#### 场景1.2: 语音打断功能
- 步骤1: AI正在播放TTS音频
- 步骤2: 用户开始说话
- 步骤3: 验证系统停止播放
- 步骤4: 验证用户语音被正确识别
- 验证点: 打断响应时间、状态恢复

#### 场景1.3: 多轮对话持续性
- 步骤1: 进行10轮以上对话
- 步骤2: 监控WebSocket连接状态
- 步骤3: 验证连接稳定性
- 验证点: 长时间运行稳定性

### 2. 权限与兼容性测试

#### 场景2.1: 麦克风权限处理
- 权限已授予场景
- 权限被拒绝场景
- 权限提示显示验证

#### 场景2.2: 浏览器兼容性
- Chrome桌面版
- Firefox桌面版
- Safari桌面版
- 移动端Chrome
- 移动端Safari

### 3. 状态管理与错误恢复

#### 场景3.1: 网络断开恢复
- 模拟WebSocket断开
- 验证自动重连机制
- 验证状态恢复

#### 场景3.2: 错误状态处理
- ASR识别错误
- TTS播放错误
- WebSocket连接错误
- 验证错误提示显示

### 4. 性能与资源测试

#### 场景4.1: 音频处理性能
- 内存使用监控
- CPU占用分析
- 电池消耗影响

#### 场景4.2: 响应时间测试
- ASR延迟测量
- TTS启动时间
- 端到端延迟

### 5. 页面导航与功能测试

#### 场景5.1: 页面间导航
- Dashboard → 对话页
- 对话页 → 设置页
- 设置页 → 仪表盘
- 验证状态保持

#### 场景5.2: 多组件协调
- 语音按钮状态同步
- 仪表盘小部件更新
- 侧边栏状态管理

## 测试执行顺序

1. **基础功能测试** (优先级: P0)
   - 页面加载
   - 路由导航
   - 核心UI渲染

2. **语音对话测试** (优先级: P0)
   - 连接建立
   - 状态流转
   - 音频播放

3. **错误处理测试** (优先级: P1)
   - 网络错误
   - 权限错误
   - 状态错误

4. **性能测试** (优先级: P1)
   - 加载性能
   - 交互响应
   - 资源占用

5. **长时间运行测试** (优先级: P2)
   - 会话持续性
   - 内存泄漏
   - 连接稳定性

## 监控与数据分析

### Sentry监控配置
```typescript
// 错误分类
- voice.websocket.error    // WebSocket连接错误
- voice.asr.error          // ASR识别错误  
- voice.tts.error         // TTS播放错误
- voice.permission.error   // 权限相关错误
- voice.state.error       // 状态管理错误

// 性能指标
- voice.connection.time    // 连接建立时间
- voice.latency.asr       // ASR延迟
- voice.latency.tts       // TTS延迟
- voice.latency.e2e       // 端到端延迟
```

### OpenReplay录制配置
```typescript
// 录制内容
- 完整用户会话
- 语音交互全过程
- 错误发生时的操作序列
- 控制台日志
- 网络请求
```

## 测试通过标准

| 指标 | 目标值 | 最低可接受值 |
|------|--------|--------------|
| 测试通过率 | ≥95% | ≥90% |
| 语音连接成功率 | ≥99% | ≥95% |
| 页面加载时间 | ≤3s | ≤5s |
| ASR延迟 | ≤500ms | ≤1000ms |
| TTS启动时间 | ≤500ms | ≤1000ms |
| 内存增长率 | ≤10MB/小时 | ≤20MB/小时 |
