# 信息架构

## 主结构

产品应收束为少数核心空间：

```text
对话
工作
记忆
任务
蜂群
我的
```

页面可以多，但主导航不要多。

## 对话

主入口。

承载：

- 文字。
- 语音。
- 文件。
- 图片。
- 任务。
- 讨论。
- App 操作请求。
- 蜂群指令。

## 工作

成果中心。

承载：

- 项目。
- 联系人。
- 专家。
- 文档。
- 战报。
- 商务洞察。

## 记忆

主人世界模型。

承载：

- 长期记忆。
- 文件。
- 照片。
- 邮件。
- 知识库。
- 证据链。
- 记忆授权。

## 任务

执行中心。

承载：

- 即时任务。
- 定时任务。
- 循环任务。
- 条件任务。
- 长链路任务。
- 执行历史。

## 蜂群

组织协作空间。

承载：

- 蜂王/蜂后控制台。
- 节点。
- 广播。
- 任务分派。
- 风险预警。
- 战报。
- 蜂群契约。

## 我的

个体配置。

承载：

- 身份。
- 人格。
- 声音。
- 关系契约。
- 权限。
- 记忆边界。
- 执行偏好。
- 安全设置。

## 移动端导航

建议底部主导航：

- 对话。
- 工作。
- 任务。
- 记忆。
- 我的。

蜂群可根据用户身份出现在工作或独立入口中；蜂王用户可以固定显示蜂群入口。

## 桌面端导航

建议侧边栏：

- 首页。
- 对话。
- 项目。
- 任务。
- 记忆。
- 文件。
- 专家。
- 蜂群。
- 审计。
- 设置。

桌面端可以承载更高信息密度。
