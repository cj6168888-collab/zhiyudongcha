# 记忆与知识库 UI

## 定位

记忆 UI 用来建立信任。

主人要能看见她记住了什么、为什么记、来自哪里、能不能改、能不能删。

## 主视图

建议分区：

- 今日新记忆。
- 候选记忆。
- 人物。
- 项目。
- 文件。
- 照片。
- 邮件。
- 时间线。
- 高敏记忆。

## 记忆卡片

每张卡片显示：

- 内容。
- 类型。
- 来源。
- 置信度。
- 敏感等级。
- 最近使用。
- 所属项目/人物。
- 是否已共享蜂群。

操作：

- 修改。
- 删除。
- 降权。
- 设为私密。
- 共享到蜂群。
- 查看来源。

## 候选记忆

候选记忆必须易处理：

- 确认保存。
- 修改后保存。
- 忽略。
- 永不记此类。

## 知识库搜索

搜索应支持：

- 自然语言。
- 时间过滤。
- 人物过滤。
- 项目过滤。
- 来源过滤。
- 敏感等级过滤。

结果应显示为什么被召回。

## 授权中心

清楚展示：

- 文件权限。
- 照片权限。
- 邮件权限。
- 日历权限。
- 联系人权限。
- 位置权限。
- 蜂群共享权限。

每项都能关闭。
