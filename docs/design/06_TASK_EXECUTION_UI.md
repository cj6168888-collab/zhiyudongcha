# 任务执行 UI

## 定位

任务 UI 让主人知道她正在做什么、做到哪、卡在哪里、是否需要主人确认。

## 任务卡片

显示：

- 任务名称。
- 目标。
- 状态。
- 风险等级。
- 截止时间。
- 当前步骤。
- 下一步。
- 证据。

## 状态

- 草稿。
- 等待确认。
- 已计划。
- 执行中。
- 阻塞。
- 完成。
- 失败。
- 取消。

## 执行进度

长链路任务显示步骤：

```text
理解目标 -> 查资料 -> 生成草稿 -> 等待确认 -> 执行 -> 验证 -> 回流
```

## 确认 UI

高风险确认必须具体：

- 她准备做什么。
- 会用哪个 App 或接口。
- 会发送/删除/共享什么。
- 对方是谁。
- 是否可撤回。

## 循环任务

循环任务要显示：

- 频率。
- 下次执行时间。
- 最近执行结果。
- 失败次数。
- 可暂停。

## 回报

完成后显示：

- 结果摘要。
- 证据链接。
- 写入了哪些记忆。
- 更新了哪些项目。
- 下一步建议。
