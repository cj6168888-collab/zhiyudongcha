# 蜂群 UI

## 定位

蜂群 UI 是组织协作空间，不是个人空间。

它必须清楚表达边界、角色、授权、任务、节点、风险和战报。

## 主视图

蜂王/蜂后视图：

- 蜂群状态。
- 节点在线。
- 当前任务。
- 风险预警。
- 广播入口。
- 战报。
- 契约和权限。

节点视图：

- 我的任务。
- 回报要求。
- 已共享资料。
- 蜂群契约。
- 风险提示。

## 边界提示

任何共享动作都要显示：

- 这是个人资料还是蜂群资料。
- 是否会被蜂王看到。
- 是否会进入审计。
- 是否可以撤回。

## 预警

不要直接写“背叛”。

使用：

- 协作风险。
- 异常行为。
- 数据外泄风险。
- 任务偏离。

预警必须显示证据，不审判人心。

## 广播

广播卡应显示：

- 目标节点。
- 内容。
- 期望结果。
- 截止时间。
- 是否需要回报。
- 风险等级。

## 战报

战报应总结：

- 做了什么。
- 谁完成了。
- 哪些异常。
- 哪些经验沉淀。
- 下一步。
