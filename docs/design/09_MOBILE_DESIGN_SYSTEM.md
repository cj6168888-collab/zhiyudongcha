# 移动端设计系统

## 定位

移动端是随身助手主体验。

## 布局

- 单手可用。
- 底部输入优先。
- 关键操作不藏太深。
- 长任务用卡片呈现。
- 高风险确认用底部弹层或全屏确认。

## 导航

建议底部导航：

- 对话。
- 工作。
- 任务。
- 记忆。
- 我的。

蜂王用户可显示蜂群入口。

## 组件

常用组件：

- 对话气泡。
- 理解卡。
- 任务卡。
- 记忆卡。
- 风险确认卡。
- 语音按钮。
- 声音试听卡。
- 授权开关。

## 视觉

- 暗色底。
- 高对比文字。
- 重点用克制高亮。
- 风险用明确色彩和文案。
- 卡片边界清晰，不嵌套过深。

## 交互

- 语音优先。
- 支持滑动归档。
- 支持长按更多。
- 支持底部确认。
- 支持撤销。

## 安全

敏感内容默认折叠或遮罩，点击后显示。
