# 觉醒问询 UI

## 定位

觉醒问询不是注册表单，而是她成为“你的她”的仪式。

## 体验目标

- 自然。
- 温柔。
- 有仪式感。
- 不压迫。
- 可跳过。
- 可之后修改。

## 流程

```text
欢迎醒来
  -> 名字和称呼
  -> 关系
  -> 人格
  -> 声音
  -> 记忆授权
  -> 执行边界
  -> 守护偏好
  -> 完成
```

## 交互方式

优先自然语言。

同时提供轻量选项：

- 温柔。
- 活泼。
- 理性。
- 幽默。
- 犀利。
- 稳重。

主人可以直接说：

```text
你叫小语，我叫老陈。你是我的助手，也是朋友。平时温柔一点，工作上直接一点。
```

系统自动提取配置，并让主人确认。

## 声音选择

用可试听卡片：

- 温柔陪伴型。
- 清醒秘书型。
- 活泼灵动型。
- 冷静参谋型。
- 严肃守护型。

每张卡片提供：

- 试听。
- 使用场景。
- 语速。
- 情绪支持。

## 授权设计

授权不要一次性吓人。

先建立关系，再分阶段引导：

- 现在只开启基础记忆。
- 后续需要文件/照片/邮件时再请求。
- 每项授权说明用途。

## 完成态

完成后展示：

- 她的名字。
- 主人的称呼。
- 关系。
- 性格摘要。
- 声音。
- 当前授权范围。
- 可随时修改入口。
