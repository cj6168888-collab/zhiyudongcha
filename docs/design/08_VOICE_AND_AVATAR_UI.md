# 声音与头像 UI

## 定位

声音和头像是她的人格外壳。

它们应该增强亲近感和状态感，但不能抢走任务完成的主线。

## 声音 UI

设置中展示：

- 当前音色。
- 试听。
- 场景绑定。
- 语速。
- 情绪支持。
- TTS provider。

场景绑定：

- 闲聊。
- 工作。
- 战略。
- 危机。
- 梦境。
- 蜂群。

## 语音状态

对话界面应显示：

- 正在听。
- 正在转写。
- 识别到说话人。
- 正在思考。
- 正在说话。

## 头像状态

头像可表达：

- 空闲。
- 聆听。
- 思考。
- 执行。
- 守护。
- 梦境。
- 蜂群广播。

## 克制原则

头像不应：

- 遮挡核心内容。
- 频繁打断任务。
- 在危机模式卖萌。
- 让用户误以为高风险动作已确认。

## 声音安全 UI

声纹和声音克隆设置必须显示：

- 用途。
- 样本位置。
- 是否本地。
- 是否上传。
- 删除入口。
- 撤回授权入口。
