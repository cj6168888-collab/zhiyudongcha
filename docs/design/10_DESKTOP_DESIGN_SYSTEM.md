# 桌面端设计系统

## 定位

桌面端适合复杂工作，不是移动端简单放大。

适合：

- 大文档。
- 项目。
- 任务编排。
- 蜂群监控。
- 审计。
- 多面板对比。

## 布局

建议：

- 左侧导航。
- 中间主工作区。
- 右侧上下文面板。
- 底部或浮动对话入口。

## 信息密度

桌面端可以更密，但必须保持层次。

避免：

- 大面积装饰英雄区。
- 卡片套卡片。
- 无意义大数字。
- 不可操作看板。

## 多面板

常见组合：

- 项目 + 任务 + 文件。
- 对话 + 理解结果 + 记忆。
- 蜂群 + 节点 + 战报。
- 文档 + 专家建议 + 修改记录。

## 快捷操作

桌面端支持：

- 快捷键。
- 命令面板。
- 拖拽文件。
- 多选批处理。
- 审计筛选。

## 风险确认

桌面端高风险确认可以使用 modal，但必须明确动作影响和数据范围。
