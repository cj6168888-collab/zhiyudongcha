# 可访问性与信任

## 可访问性

最低要求：

- 文字对比度足够。
- 触控目标不小于 44px。
- 交互元素有可读标签。
- 不只用颜色表达状态。
- 支持键盘操作。
- 动画不过度。
- 文本不溢出。

## 信任设计

用户必须知道：

- 她正在听吗？
- 她记住了什么？
- 她准备做什么？
- 她是否会外传数据？
- 她是否已经执行？
- 是否可以撤销？

## 权限透明

权限界面应显示：

- 权限名称。
- 用途。
- 数据范围。
- 是否本地处理。
- 是否会上传。
- 关闭入口。

## 审计可见

关键动作应可查看：

- 读取了什么。
- 调用了什么。
- 发给谁。
- 花了多少。
- 结果是什么。

## 危机模式

危机模式 UI 应：

- 降低装饰。
- 强化下一步。
- 提供现实求助建议。
- 避免玩笑。
- 避免复杂选项。

## 错误恢复

错误提示要说明：

- 发生了什么。
- 是否造成影响。
- 现在能做什么。
- 是否已保留现场。
