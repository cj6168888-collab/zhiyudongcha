## 场景演示

### 场景：陈哥来电

**对话内容：**
```
陈哥: 我晚上10点到郑州，你有时间来接我吗？
小王: 有的兄弟，需要我帮你安排房间吗？到了咱们去小酌一杯。
陈哥: 好的陈哥，10点见，我从高铁站东出站口出。
陈哥: 好的兄弟，我的车牌号0L5Z7
```

**小星自动识别：**

| 提取项 | 值 |
|--------|-----|
| 约定类型 | 接人 |
| 时间 | 今晚 22:00 |
| 地点 | 郑州高铁站 东出站口 |
| 联系人 | 陈哥 |
| 车牌号 | 0L5Z7 |
| 备注 | 喝酒 |

**小星自动执行：**

```
✅ 已创建日历：「接陈哥 - 郑州高铁站」
✅ 已设置提醒：「21:30 出发去接陈哥」
✅ 已设置导航：「郑州高铁站 东出站口」
✅ 车辆提醒：「今晚需要开车，0L5Z7」

📱 主动建议：
   • 是否需要帮你们预订酒店？
   • 是否查询今晚郑州天气？
```

### 场景：自然语言任务

**用户说：** "帮我查一下最新科技型中小企业扶持政策"

**小星自动执行：**

```
1. 🔍 搜索相关网站
2. 📄 分析页面内容
3. 📋 提取关键政策信息
4. 📱 推送汇报结果
```

**汇报：**
```
📢 科技型中小企业扶持政策（2024）

主要优惠：
• 研发费用加计扣除比例提高至 120%
• 最高补贴 50 万创新券
• 贷款贴息最高 200 万

申报条件：
• 上年度营业收入 < 2000万
• 科技人员占比 > 10%
• 研发投入占比 > 3%
```

## API 接口

### 主动服务

```bash
# 处理消息，自动识别约定
POST /api/proactive/process
{
  "content": "今晚10点接陈哥，车牌0L5Z7",
  "source": "wechat",
  "participants": ["陈哥"]
}

# 模拟测试
POST /api/proactive/simulate

# 获取即将到来的事件
GET /api/proactive/upcoming?hours=24
```

### 自然语言任务

```bash
# 自然语言指令
POST /api/agent/nl
{
  "command": "帮我查最新科技政策"
}

# 查看能力
GET /api/agent/nl/capabilities
```

### 浏览器自动化

```bash
# 执行浏览器操作
POST /api/agent/browser/execute
{
  "profileId": "xxx",
  "actions": [
    { "type": "navigate", "value": "https://kjj.xxx.gov.cn" }
  ]
}

# 获取页面快照
GET /api/agent/browser/snapshot?profileId=xxx&url=https://...
```

## 工作原理

### ProactiveAgent 如何工作

```
收到消息
    │
    ▼
┌─────────────────────────────────────┐
│  AI 分析对话内容                      │
│                                      │
│  "10点接人" → 识别为「约定」         │
│  "高铁站" → 识别为「地点」           │
│  "0L5Z7" → 识别为「车牌号」         │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  生成行动                            │
│                                      │
│  日历事件: 22:00 接陈哥             │
│  提醒: 21:30 出发                   │
│  导航: 郑州高铁站                   │
│  物品: 车牌号 0L5Z7                 │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  自动执行 + 推送                    │
│                                      │
│  [日历] ✓                          │
│  [提醒] ✓                          │
│  [建议] "是否预订酒店？"           │
└─────────────────────────────────────┘
```


## 特性对比

| 特性 | 传统助手 | 小星 |
|------|---------|------|
| 消息处理 | 等命令 | 自动识别 |
| 约定提取 | 手动记录 | 自动提取 |
| 提醒设置 | 手动创建 | 自动创建 |
| 需求预测 | 无 | 主动建议 |
| 网站操作 | 需要配置 | 自主分析 |
| 表单填写 | 需要预设 | AI 识别 |
