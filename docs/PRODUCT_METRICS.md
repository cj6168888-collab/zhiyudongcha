# 产品指标体系

## 目的

本文件定义生语助手从 MVP 到长期演进的产品度量方式。指标不是为了制造报表，而是为了判断她是否真的做到了：

```text
功能强大，但操作简单。
懂主人，能守护，会执行，可追溯。
```

所有指标必须服务产品闭环，避免只统计按钮点击、页面访问和无意义活跃。

## 北极星指标

### 主人有效闭环次数

定义：主人通过自然语言或语音交代一件事，系统完成理解、确认、生成记忆/项目/任务、执行或计划、回流结果的次数。

计数条件：

- 有明确输入。
- 有结构化理解结果。
- 至少生成一种资产：记忆、项目、任务、文档、提醒、审计记录。
- 有完成、失败、阻塞或等待确认状态。
- 结果可追溯。

不计入：

- 纯闲聊。
- 只有回答，没有沉淀。
- 系统伪装完成但没有证据。
- 高风险动作绕过确认。

## 一阶指标

| 指标 | 说明 | 目标方向 |
| --- | --- | --- |
| 对话模式路由准确率 | 闲聊、任务、记忆、危机、蜂群等模式是否判断正确 | 越高越好 |
| 结构化理解完整率 | 人物、时间、任务、项目、风险、缺口等字段是否完整 | 越高越好 |
| 任务成功回流率 | 任务完成后是否写回状态、证据、记忆或项目 | 越高越好 |
| 高风险拦截正确率 | 发送、删除、外传、付款等动作是否被正确确认 | 越高越好 |
| 误执行率 | 未经授权或理解错误导致的执行 | 越低越好 |
| 记忆可控率 | 记忆是否可查看、修改、删除、追溯来源 | 越高越好 |
| 主人修正率 | 主人需要修改理解结果、记忆或任务的比例 | 越低越好 |
| 失败诚实率 | 失败时是否标记失败并说明原因 | 越高越好 |
| 成本有效率 | 完成一次闭环的 token、工具和时间成本 | 越低越好 |

## 信任指标

生语助手越强，越需要被信任。信任指标优先级高于表面效率。

| 指标 | 定义 |
| --- | --- |
| 确认清晰率 | 高风险确认是否说明动作、对象、数据、影响、可撤回性 |
| 审计覆盖率 | 敏感读取、外传、删除、共享、蜂群广播是否有审计 |
| 敏感外传说明率 | 外传前是否说明发什么、给谁、为什么 |
| 权限撤回可达率 | 用户是否能在设置中找到撤回入口 |
| 记忆来源可见率 | 长期记忆是否显示来源和置信度 |
| 危机模式合规率 | 危机中是否稳定、少装饰、给现实下一步 |

## AI 质量指标

### 对话理解

- 意图识别准确率。
- 模式路由准确率。
- 该追问时追问率。
- 不该执行时拦截率。
- 闲聊不落库率。
- 重要事实候选记忆召回率。

### 记忆

- 该想起时召回率。
- 不该想起时抑制率。
- 过期信息误用率。
- 删除后召回违规次数。
- 记忆合并重复率。

### 执行

- 任务状态正确率。
- 工具选择成功率。
- 失败恢复建议可用率。
- 长链路任务中断恢复率。
- 执行证据覆盖率。

## 产品健康分层

### P0 健康线

MVP 必须达到：

- 高风险动作 100% 经过确认。
- 删除、外传、共享、付款类动作 100% 留审计。
- 失败不能伪装成功。
- 主闭环必须至少覆盖对话、记忆、项目、任务、确认、回流。

### P1 成长线

第一阶段增强应追踪：

- 每周主人有效闭环次数。
- 主人修正率。
- 记忆召回满意度。
- 任务完成回流率。
- 平均一次闭环成本。

### P2 规模线

蜂群和多设备能力上线后追踪：

- 节点任务按时回报率。
- 蜂群预警证据覆盖率。
- 组织资料误共享率。
- App 操作成功率。
- 远程执行失败恢复率。

## 数据采集原则

1. 默认不采集完整敏感内容。
2. 指标优先记录结构化事件和摘要，不记录原文。
3. 日志必须脱敏。
4. 指标事件必须带 requestId、ownerId 或匿名 ownerHash、sessionId、riskLevel。
5. 任何用于产品分析的个人数据都必须可关闭、可删除。
6. 蜂群指标必须区分个人空间和组织空间。

## 事件建议

| 事件 | 触发时机 |
| --- | --- |
| `conversation.mode_routed` | 对话模式判断完成 |
| `conversation.structured` | 结构化理解完成 |
| `memory.candidate_created` | 候选记忆生成 |
| `memory.confirmed` | 主人确认保存 |
| `task.created` | 任务创建 |
| `task.state_changed` | 任务状态变化 |
| `risk.confirmation_required` | 高风险确认出现 |
| `risk.confirmation_approved` | 主人确认执行 |
| `execution.completed` | 执行完成 |
| `execution.failed` | 执行失败 |
| `audit.recorded` | 审计写入 |

## 指标复盘节奏

- 每个 release 复盘 P0 指标。
- 每周复盘主闭环指标。
- 每月复盘记忆质量、成本、误执行和用户信任。
- 每次高风险事故后更新指标和守护协议。
