# ADR 0003: 记忆与数据治理

## Status

Accepted

## Context

生语助手的长期价值来自记忆，但记忆也带来隐私、过期、误召回、蜂群误共享和删除权问题。

## Decision

记忆采用分层治理：

- 原始层保存来源或引用。
- 解析层提取结构化内容。
- 语义层建立检索。
- 结构层转成人物、项目、任务、事件、证据。
- 反思层在梦境中生成长期模式。

长期记忆必须包含：

- ownerId。
- scope。
- sensitivity。
- sourceId。
- confidence。
- status。
- lastVerifiedAt。

删除后的记忆不得参与召回。个人记忆默认不进入蜂群。

## Consequences

- 记忆功能必须有来源追溯。
- 高敏资料进入长期记忆前需要确认。
- 蜂群共享必须显式授权。
- 记忆迁移和删除必须有备份和审计策略。
