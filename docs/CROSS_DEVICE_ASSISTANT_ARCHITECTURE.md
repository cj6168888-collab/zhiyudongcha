```
│        ▼                                                   │
│  ┌──────────────┐                                         │
│  │  理解意图    │  →  微信发消息                          │
│  └──────────────┘                                         │
│        │                                                   │
│        ▼                                                   │
│  ┌──────────────┐                                         │
│  │  识别实体    │  →  张三, 明天开会                      │
│  └──────────────┘                                         │
│        │                                                   │
│        ▼                                                   │
│  ┌──────────────┐                                         │
```

### 2.4 AuthorizationManager（授权管理器）

```
职责：
• 金额阈值控制
• 全权授权
• 权限撤销

用户可以说的授权命令：
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  "这件事交给你了"                                          │
│      → 单次授权，本次直接执行                               │
│                                                             │
│  "订餐这种事以后都交给你了"                                 │
│      → 永久授权，以后类似操作直接处理                        │
│                                                             │
│  "你自己看着办"                                            │
│      → 全权授权，所有操作（除敏感）直接处理                  │
│                                                             │
│  "以后都听你的"                                            │
│      → 全权授权                                            │
│                                                             │
│  金额阈值可以自定义:                                        │
│  "小星，超过200块的都要问我"                               │
│      → 设置 auto=200, confirm=1000                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 四、API 设计

### 4.1 跨设备对话

```bash
POST /api/cross-device/chat
{
  "message": "帮我用微信给张三发消息"
}

Response:
{
  "success": true,
  "response": {
    "id": "resp_xxx",
    "type": "execute",
    "message": "✅ 已完成！\n发送微信消息给张三",
    "execution": {
      "taskId": "task_xxx",
      "progress": 100
    },
    "devices": {
      "available": ["我的手机", "我的电脑"],
      "used": ["我的手机"]
    }
  }
}
```

### 4.2 设备管理

```bash
# 获取设备列表
GET /api/cross-device/devices

# 获取设备程序列表
GET /api/cross-device/devices/:id/programs

# 获取设备能力描述
GET /api/cross-device/programs
```

### 4.3 直接操作

```bash
# 发送微信消息
POST /api/cross-device/tools/wechat
{
  "deviceId": "device_xxx",
  "contact": "张三",
  "message": "明天开会"
}

# 打开电脑应用
POST /api/cross-device/tools/open-app
{
  "appName": "VSCode"
}

# 拨打电话
POST /api/cross-device/tools/call
{
  "deviceId": "device_xxx",
  "phoneNumber": "13800138000"
}
```

### 4.4 授权管理

```bash
# 查看授权设置
GET /api/assistant/permissions

# 修改金额阈值
PUT /api/assistant/permissions/thresholds
{
  "auto": 200,
  "confirm": 2000
}

# 查看授权列表
GET /api/assistant/authorizations

# 撤销授权
DELETE /api/assistant/authorizations/:id
```

### 6.2 程序动作定义

```typescript
// 每个程序都定义可执行的动作
interface ProgramAction {
  name: string;           // 动作名称
  description: string;     // 动作描述
  invocation: {
    type: 'intent' | 'deeplink' | 'command' | 'shortcut';
    value: string;         // 调用方式
  };
  parameters?: Array<{
    name: string;
    type: 'string' | 'number' | 'file';
    required: boolean;
    description: string;
  }>;
}

// 示例：微信

  name: '发送消息',
```
