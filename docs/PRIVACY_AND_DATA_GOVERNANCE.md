# 隐私与数据治理

## 目的

生语助手的核心能力建立在长期记忆、文件读取、邮件理解、语音、照片、App 操作和蜂群协作上。越懂主人，越必须可控、可撤回、可审计。

本文件把 [02_SOVEREIGN_GUARDIAN_PROTOCOL.md](./02_SOVEREIGN_GUARDIAN_PROTOCOL.md) 中的原则落到数据生命周期。

## 数据治理原则

1. 主人拥有个人数据的最终控制权。
2. 默认最小必要读取。
3. 默认本地优先处理。
4. 高敏数据默认不外传。
5. 个人空间和蜂群空间默认隔离。
6. 记忆必须可查看、可修改、可删除、可导出。
7. 所有高风险数据动作必须审计。

## 数据分类

| 等级 | 类型 | 示例 | 默认策略 |
| --- | --- | --- | --- |
| S0 | 普通公开信息 | 公开网页、普通偏好 | 可索引，可摘要 |
| S1 | 普通工作资料 | 项目文档、会议纪要 | 授权后索引 |
| S2 | 私人上下文 | 邮件、联系人、聊天、日历 | 本地优先，外传受控 |
| S3 | 高敏资料 | 合同、财务、身份证、照片、私密关系 | 严格确认，默认遮罩 |
| S4 | 极高敏资料 | 密钥、密码、验证码、医疗、法律核心资料、声纹样本 | 默认禁止外传，强确认 |

## 数据生命周期

```text
授权
  -> 读取
  -> 解析
  -> 索引
  -> 候选记忆
  -> 主人确认
  -> 长期保存
  -> 使用和召回
  -> 修改、导出、删除或过期
```

每一步都必须记录来源、权限、敏感等级和可追溯标识。

## 授权

授权界面必须说明：

- 读取什么数据。
- 用来做什么。
- 是否本地处理。
- 是否可能上传给模型或第三方。
- 是否进入长期记忆。
- 是否进入蜂群空间。
- 如何关闭。

禁止把多个高敏权限打包成一个含糊授权。

## 读取和解析

读取规则：

- 只读任务需要的数据范围。
- 能读索引不读全文。
- 能读摘要不读原文。
- 能本地解析不上传。
- 解析失败不扩大权限，先说明卡点。

解析输出必须标注：

- sourceId。
- sourceType。
- sensitivity。
- ownerId。
- createdAt。
- hash 或可追溯位置。

## 记忆保存

长期记忆默认走候选机制。

可以自动保存的内容：

- 低敏偏好。
- 主人明确要求记住的事项。
- 已确认项目和任务状态。

需要确认的内容：

- 私密关系。
- 财务、合同、法律资料。
- 邮件和聊天中的敏感事实。
- 声纹、声音、身份信息。
- 可能进入蜂群的个人资料。

## 使用和召回

召回记忆时必须控制范围：

- 只召回当前任务必要内容。
- 不把 S3/S4 直接塞入外部模型上下文。
- 对过期或低置信内容标注不确定。
- 删除的记忆不得召回。
- 蜂群任务不得默认召回个人私密记忆。

## 外传

外传包括：

- 发给第三方模型。
- 上传到云服务。
- 发送给联系人。
- 共享到蜂群。
- 写入外部 App 或网页。

外传确认必须说明：

- 发什么。
- 发给谁。
- 为什么需要。
- 是否有本地替代方案。
- 是否可撤回。
- 是否会留下副本。

## 删除和导出

主人必须能：

- 删除单条记忆。
- 删除某类记忆。
- 删除某个来源生成的记忆。
- 导出个人记忆。
- 撤回数据源授权。
- 删除声纹和声音样本。

删除策略：

- 普通记忆可软删除并从召回中排除。
- 高敏原始资料删除前提示影响。
- 永久删除必须强确认。
- 删除动作必须审计。

## 蜂群数据边界

蜂群空间只能使用：

- 主人明确共享的个人资料。
- 组织任务产生的资料。
- 蜂群契约允许的节点状态。
- 节点回报和战报。

默认不得共享：

- 私人照片。
- 私人邮件。
- 私人聊天。
- 私人联系人。
- 私人位置。
- 与组织任务无关的文件。

## 声音和生物身份

声纹、声音克隆、录音样本属于 S4。

要求：

- 明确授权。
- 本地优先。
- 可删除样本。
- 可撤回授权。
- 禁止冒充主人或第三方。
- 外传样本前强确认。

## 数据事故响应

疑似事故包括：

- 敏感数据误外传。
- 越权读取。
- 删除不可恢复。
- 蜂群误共享个人资料。
- 日志泄露密钥或原文。

响应流程：

1. 立即停止相关任务和自动化。
2. 保留审计证据。
3. 判断影响范围。
4. 通知主人或管理员。
5. 撤回、删除或轮换受影响资料。
6. 复盘并更新守护协议、测试和监控。
