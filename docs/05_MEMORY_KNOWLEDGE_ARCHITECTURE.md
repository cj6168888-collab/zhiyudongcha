# 记忆与知识库架构

## 目标

主人可以选择对她没有秘密，但系统必须让这种亲密关系可控、安全、可恢复。

记忆系统的目标不是保存聊天记录，而是建立主人的长期世界模型。

## 知识来源

她可以在授权下读取：

- 手机文件。
- 照片和截图。
- 邮件和附件。
- 日历。
- 通讯录。
- 录音和会议。
- 聊天导出。
- 浏览器资料。
- 电脑文件。
- 项目资料。
- 蜂群共享资料。

## 本地优先

默认策略：

1. 本地索引。
2. 本地解析。
3. 本地摘要。
4. 只把必要片段发送给模型。
5. 敏感内容外传前必须确认或使用明确策略。

## 记忆分层

### 1. 原始层

保存原始文件、录音、照片、邮件或引用位置。

要求：

- 不随意改写。
- 保留来源。
- 支持追溯。
- 支持撤回和删除。

### 2. 解析层

从原始数据中提取：

- OCR 文本。
- 文件正文。
- 邮件正文。
- 元数据。
- 人名、时间、地点、事项。
- 附件关联。

### 3. 语义层

建立可检索的语义知识：

- 向量索引。
- 标签。
- 摘要。
- 主题。
- 相似内容。
- 相关人物和项目。

### 4. 结构层

转成系统实体：

- 人物。
- 项目。
- 任务。
- 事件。
- 文档。
- 证据。
- 风险。
- 偏好。
- 组织资产。

### 5. 反思层

梦境中生成：

- 长期模式。
- 主人偏好。
- 关系变化。
- 项目风险。
- 重复问题。
- 行动建议。

## 记忆类型

| 类型 | 用途 |
| --- | --- |
| 人物记忆 | 关系、角色、偏好、承诺、风险 |
| 项目记忆 | 背景、目标、资料、进度、阻塞 |
| 任务记忆 | 待办、负责人、截止时间、状态 |
| 文件记忆 | 文件内容、来源、版本、关联项目 |
| 事件记忆 | 时间线、发生了什么、涉及谁 |
| 偏好记忆 | 主人的习惯、风格、决策偏好 |
| 证据记忆 | 合同、截图、邮件、录音、出处 |
| 蜂群记忆 | 组织经验、任务报告、共享资料 |

## 记忆操作

主人必须能：

- 查看她记住了什么。
- 修改错误记忆。
- 删除某条记忆。
- 删除某类记忆。
- 导出记忆。
- 限制某条记忆的使用范围。
- 把个人记忆共享给蜂群。
- 把蜂群资料复制到个人空间。

## 敏感等级

| 等级 | 示例 | 默认策略 |
| --- | --- | --- |
| S0 | 普通偏好、公开资料 | 可索引 |
| S1 | 普通工作文件、项目资料 | 授权后索引 |
| S2 | 邮件、联系人、聊天记录 | 本地优先，外传受控 |
| S3 | 合同、财务、身份、照片、私密关系 | 高敏识别，严格确认 |
| S4 | 密钥、密码、验证码、医疗、法律核心资料 | 默认禁止外传，强确认 |

## 知识库不是垃圾堆

读取大量信息后，系统必须自动清理：

- 去重。
- 合并。
- 过期标记。
- 来源校验。
- 冲突提示。
- 低价值内容降权。
- 重要内容加固。

目标是越来越聪明，而不是越存越乱。
