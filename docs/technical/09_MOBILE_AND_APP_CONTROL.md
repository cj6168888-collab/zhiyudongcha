# 移动端与 App 控制

## 目标

她不需要把所有能力都做成内置页面。她应能在授权下读取手机资料、理解屏幕、操作 App，借用现有工具完成任务。

## 能力范围

- 文件读取。
- 照片和截图读取。
- 邮件接入。
- 日历和联系人。
- 语音唤醒。
- ASR。
- TTS。
- 声纹识别。
- App 屏幕理解。
- 点击、输入、滑动。
- 结果截图和 OCR。

## Android 原生能力

可用方向：

- AccessibilityService。
- Storage Access Framework。
- MediaStore。
- Notification Listener。
- Foreground Service。
- Speech / Audio APIs。
- 系统分享和 Intent。

## 权限原则

所有手机权限必须：

- 清楚说明用途。
- 可关闭。
- 最小必要。
- 本地优先。
- 高敏外传前确认。

## App 操作原则

1. 先理解当前屏幕，再操作。
2. 操作前判断风险。
3. 外部影响动作必须确认。
4. 不绕过验证码和系统安全。
5. 每次操作保留关键证据。

## 语音

语音配置来自 `VoiceProfile`。

支持：

- 多 TTS provider。
- 多音色。
- 场景音色路由。
- 情绪语音。
- 语速和音高。

## 声纹

声纹用于分辨谁在说话。

要求：

- 明确授权。
- 本地优先。
- 可删除样本。
- 不用于未经授权的身份冒充。
