# 安全、隐私与授权

## 原则

所有强能力都必须服从主权守护协议。

安全不是后补功能，而是系统底座。

## 授权模型

权限判断应基于：

- role。
- userId。
- grants。
- resourceType。
- actionType。
- scope。
- swarm contract。

不能只靠前端隐藏按钮。

## 数据敏感等级

| 等级 | 示例 | 默认策略 |
| --- | --- | --- |
| S0 | 普通偏好、公开资料 | 可索引 |
| S1 | 普通工作文件、项目资料 | 授权后索引 |
| S2 | 邮件、联系人、聊天记录 | 本地优先，外传受控 |
| S3 | 合同、财务、身份、照片、私密关系 | 高敏识别，严格确认 |
| S4 | 密钥、密码、验证码、医疗、法律核心资料 | 默认禁止外传，强确认 |

## 动作风险等级

| 等级 | 类型 | 默认处理 |
| --- | --- | --- |
| L0 | 观察 | 自动 |
| L1 | 整理 | 自动并留记录 |
| L2 | 草拟 | 自动草拟，不发送 |
| L3 | 外部影响 | 确认 |
| L4 | 高风险 | 强确认 |
| L5 | 禁止或交给主人 | 不代做 |

## 外传确认

任何敏感数据外传前必须说明：

- 发什么。
- 发给谁。
- 为什么。
- 有什么风险。
- 是否有本地替代方案。

## 删除保护

默认不直接永久删除。

优先：

- 回收站。
- 隔离区。
- 标记删除。
- 可恢复备份。

永久删除必须强确认并审计。

## 声音和生物身份

声纹、录音样本、声音克隆属于敏感身份数据。

要求：

- 明确授权。
- 可删除。
- 可撤回。
- 本地优先。
- 禁止冒充主人或第三方。

## 蜂群安全

蜂王可拥有组织态势感知权，但必须来自蜂群契约。

个人记忆默认不进入蜂群。

蜂群预警只报告证据和风险，不直接审判人心。

## 审计

必须审计：

- 高风险动作。
- 敏感数据读取。
- 敏感数据外传。
- 权限变更。
- 蜂群广播。
- 节点异常。
- 删除和共享。

审计记录必须可追溯 requestId。
