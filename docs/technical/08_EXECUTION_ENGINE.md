# 执行引擎

## 目标

执行引擎让她从“会说”变成“会办事”。

它负责把自然语言目标变成可追踪、可确认、可执行、可回流的任务。

## 任务类型

- 即时任务。
- 定时任务。
- 循环任务。
- 条件任务。
- 长链路任务。
- 蜂群任务。

## 状态机

```text
DRAFT
  -> READY_FOR_CONFIRMATION
  -> SCHEDULED
  -> RUNNING
  -> BLOCKED
  -> DONE
  -> FAILED
  -> CANCELLED
```

## 执行步骤

```text
理解目标
  -> 补齐上下文
  -> 判断风险
  -> 检查权限
  -> 选择工具
  -> 生成计划
  -> 必要时确认
  -> 执行
  -> 验证结果
  -> 回流记忆/项目/任务
```

## 确认点

必须确认：

- 发送消息。
- 提交表单。
- 上传文件。
- 付款。
- 删除。
- 改共享权限。
- 读取或外传高敏数据。
- 创建密钥或持久授权。

## 执行记录

每次执行应记录：

- taskId。
- actor。
- tool。
- inputSummary。
- riskLevel。
- startedAt。
- finishedAt。
- result。
- evidence。
- auditId。

## 失败处理

失败时必须：

- 标记失败原因。
- 保留已完成步骤。
- 给出下一步建议。
- 不假装完成。
- 必要时请求主人决策。

## 回流

执行结果进入：

- 任务状态。
- 项目更新。
- 记忆。
- 审计。
- 战报。
- 梦境复盘。
